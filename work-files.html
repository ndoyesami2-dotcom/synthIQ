Work Files

Import lists files in the browser only—the originals stay on your PC. Click a saved session to download a .txt summary to your computer (usual Downloads folder). Use Browse folder / Folder with node server.cjs on localhost if you want File Explorer.

On localhost (Windows), use Browse folder after List to pick a folder and open it in Explorer. When you save an import, you can optionally link a folder the same way.

Imported sessions

Click a session to download a .txt file with that session’s file list. Use List for the viewer; Folder opens a linked folder via the server on localhost.
